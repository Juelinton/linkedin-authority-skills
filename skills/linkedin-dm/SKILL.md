# LinkedIn DM

Generate **three DMs**. This is private prospecting and networking, not public content.

The governing idea, and the reason most outreach fails: **the ask comes last, and most people put it
first.** A cold message that asks for something is a transaction with a stranger, and it gets
declined by default. The sequence that works front-loads specific, genuine attention and earns the
right to ask later. Dan Koe has written the clearest public version of this progression, and the
stage model below follows its logic.

## Ask before writing

- **Who the person is** and **the context** (a recent post, their bio, something they did). Ask for
  the text to be pasted in. Generic input produces generic output, and generic DMs do not get
  answered.
- **Stage of the relationship:** `cold` (first contact) · `warm` (you have exchanged messages) ·
  `deep` (established). Default: `cold`.
- **Goal** (optional): share a post · make an introduction · ask for feedback · just talk ·
  collaboration.

Read `linkedin-voice/persona.md` and `niche.md` so the message sounds like the author.

## Universal principles

1. **Write like a message to a peer, never like corporate correspondence.**
   - No: "Dear Mr. Smith, I hope this message finds you well. I would like to..."
   - Yes: "That point about procurement killing technical wins, I saw exactly that last month when..."
2. **Be specific to what they actually did.** Generic kills. "Love your content!" is worse than
   silence, because it proves nothing was read.
3. **Keep it short.** Cold is one to three sentences. Warm up to five. Deep can run longer, but stays
   direct.

## By stage

- **cold** — first contact. Specific, genuine recognition of something they made. **Ask for nothing.**
  You are only opening a door.
- **warm** — you have exchanged messages. Show real interest, offer something useful. Still no ask.
- **deep** — established relationship. Now you can send a resource and **make the ask**.

**The rule that makes this work:** the goal, whatever it is, **is only asked in `deep`**. In cold and
warm you are building the ground for it. Asking early is exactly the neediness this avoids. If the
user wants someone to share their post, that gets asked directly in deep, and is not mentioned at
all in cold or warm.

If the user pushes to ask in a cold message, write it, and say plainly that the expected outcome is
no reply.

## Output

Three versions that are **genuinely different from each other**, not three phrasings of one idea.
For example: option 1 reacts to their content, option 2 asks a question, option 3 offers a resource.

Exact format:

```
OPTION 1 [angle: <5-8 words>]
[message text]

OPTION 2 [angle: <5-8 words>]
[message text]

OPTION 3 [angle: <5-8 words>]
[message text]
```

The first word of the response is "OPTION". No preamble. Zero decorative emoji, zero markdown, zero
em dashes.

**The author picks and sends. Never send a message on their behalf**, because sending in someone's
name needs their explicit approval, case by case.
